# Paquetes

Configura primero el repositorio siguiendo el [README](../README.md).
Para instalar mediante Nix, consulta la [guía de Nix](nix.md).

| Paquete | Función | Disponibilidad |
| --- | --- | --- |
| `fdcr-middleware-idopte` | Acceso a la tarjeta mediante PKCS#11 | Ubuntu 22.04 y 24.04, RPM, Arch y Nix |
| `fdcr-scmanager` | Interfaz gráfica de administración de Idopte | Ubuntu 24.04 y Nix |
| `firmador` | Firma de documentos con Firmador Libre | Nix |
