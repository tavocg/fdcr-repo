Repositorio de dependencias para Firma Digital en Costa Rica

- [Instalación manual](doc/install.md)
- [Paquetes](doc/packages.md)
- [Construcción](doc/build.md)
- [Nix](doc/nix.md)

## Instalación

```sh
curl -fsSL https://tavocg.github.io/fdcr-repo/install.sh | sudo sh
```

Luego, instale el paquete con el gestor de tu distribución. Por ejemplo, en Ubuntu:

```sh
sudo apt install fdcr-middleware-idopte
```

Para configurar el repositorio sin el script, ver la
[guía de instalación manual](doc/install.md).
